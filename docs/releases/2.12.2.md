# Linubot 2.12.2

This is the first published build of the [2.12 improvements](https://github.com/agent-sh/linubot/blob/v2.12.0/docs/releases/2.12.0.md):
Tiyuvta browser signup/sign-in and preselection, checked release automation,
screenshot retention settings, expanded tests, smaller Linux packages,
focused runtime/routes modules, and supervised in-app updates.

- Install the available Android SDK package `platforms;android-37.0` while
  retaining `compileSdk 37` and `targetSdk 35`.
- Disable electron-builder's implicit publishing. Only the checked tag workflow
  may upload and publish after all acceptance gates pass.
- Recognize public Cargo build paths only in the byte-identical pinned workspace
  release with matching provenance. Private paths in custom or tampered binaries,
  application assets and runners remain rejected.

The immutable v2.12.0 and v2.12.1 tags record failed, unpublished attempts.
The unintended v2.12.1 draft was removed; no public release was replaced.
