# Linubot 2.12.0

- Sign up or sign in to Tiyuvta in your browser. Tiyuvta is preselected for new connections, with its model catalog available before entering a key.
- Prepare and publish releases through one checked pipeline, with source, packaged desktop, Android, secret-scan and artifact-integrity gates.
- Choose screenshot retention in Settings and clear expired cached images while preserving active workspaces, conversations and browser profiles.
- Expand deterministic test coverage and desktop scenarios for connected tools, phone settings, provider sign-in and update boundaries.
- Reduce the Linux download and installed footprint by removing redundant bundled files and unused locale data.
- Split runtime context, tool definitions, approvals and computer routes into focused modules while preserving their existing behavior.
- Hand off in-app updates to a supervised desktop process, with service restart and recovery on supported Linux installations.

Managed installations on 2.11.0 and earlier retain their existing updater until
this version is installed. See [installation guidance](../INSTALLATION.md) for
the initial upgrade path and systems without a user service manager.
