# Linubot 2.12.1

This is the first published build of the [2.12 improvements](2.12.0.md): Tiyuvta
browser signup/sign-in and preselection, checked release automation, screenshot
retention settings, expanded tests, smaller Linux packages, focused runtime and
route modules, and supervised in-app updates.

- Correct the hosted release prerequisite to install the available Android SDK
  package `platforms;android-37.0`. Keep `compileSdk 37` and `targetSdk 35`.
- Exercise that exact SDK installation in regular Android CI before release.

The immutable `v2.12.0` tag is retained for traceability. Its hosted release
failed during SDK setup before building or publishing any assets. This patch
uses the existing tag-triggered publisher and the same validation gates.
