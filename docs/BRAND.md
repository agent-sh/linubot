# Linubot brand

The mark is a friendly teal penguin robot: a small Linux helper with a clear
face, rounded body and warm accents. The wordmark pairs that mascot with
“Linubot”. The mark represents the application; individual bots keep their own
mascots and personalities.

## Assets

| File | Use |
| --- | --- |
| `web/assets/logo.png` | Mascot and wordmark for the README and wider brand placements |
| `web/assets/icon.png` | Standalone mascot for compact application identity |
| `desktop/icon.png` | Desktop packaging, launcher and tray icon |

Use the icon at compact sizes and the complete logo where the name should be
visible. Preserve proportions and leave clear space around the mark. Keep the
main interface quiet so bot mascots and conversation content remain prominent.

## Creation and provenance

These are AI-generated raster assets created for Linubot. The generation brief
called for an original, approachable penguin robot in teal with a readable
wordmark, simple shapes and an uncluttered background suitable for a Linux app
icon.

that those providers endorse Linubot.
